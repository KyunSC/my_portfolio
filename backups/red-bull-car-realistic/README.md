# Red Bull-only realistic car

These three components preserve the working version before the full team selector.
The original Red Bull image remains at public/images/red-bull-racing.webp.

Restore from the project root:

```sh
cp backups/red-bull-car-realistic/RedBullCar.tsx components/RedBullCar.tsx
cp backups/red-bull-car-realistic/F1Car.tsx components/F1Car.tsx
cp backups/red-bull-car-realistic/F1IntroCar.tsx components/F1IntroCar.tsx
```

The older hand-drawn SVG is also preserved in backups/red-bull-car-original.
